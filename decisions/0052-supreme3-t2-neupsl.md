# ADR 0052-s3: supreme3 — T2 を本来型 NeuPSL に置換する

- 状態: 採用
- 日付: 2026-07-16
- 基点: planA-supreme2@main(db117f4)のスナップショット。supreme3 は「T2 のみを本来の
  NeuPSL に置き換え、それ以外(T0/T1/T3/quality/scene/gate/共有基盤/ハーネス/規律)は
  supreme2 と同一」を不変条件とする実験リポジトリ。
- 関連: supreme2 ADR 0015/0016/0017(T2 の従来ルール)・0040/0042(mode 分岐)・
  0049/0050(評価規律: 能力評価は strict OFF)・0025(学習の≥ガード)。

## 背景

supreme2 の T2 は NeuPSL-lite と呼ばれるが、実態は「固定重みの加点式ルール+argmax
(mode のみヒステリシス)」であり、本来の NeuPSL の中核であるニューラル述語・結合 MAP
推論・重み学習を持たない。supreme3 は T2 に限りこれを本来型に置き換え、宣言的ルール+
学習がハードコード規則に対してどれだけ機能するかを同一土俵で検証する。

## 決定

1. **新モジュール `src/supreme/neupsl.py`** に本来型 NeuPSL を実装する(stdlib のみ・乱数/時刻なし):
   - **ニューラル述語**: 9 述語(ConvEv / AddrEv / SpkOnly / CrowdEv / NearEv / SpeechSrc /
     HumanSrc / ObjSrc / LowQ)。各述語は入力 1〜4 次元 → 隠れ3(tanh)→ sigmoid の微小 MLP。
     初期化は決定的擬似乱数列(sin ベース)、出力バイアスは −2.0(未学習時はほぼ沈黙し、
     学習で立ち上がる)。総学習パラメータ 160(ルール重み 28 + MLP 132)。
   - **ルールプログラム**: Łukasiewicz 緩和の重み付き含意 28 本。supreme2 の規則の宣言化
     (risk=danger → emergency 等)+ 層間整合 4 本(emergency→source_alarm 等。supreme2 では
     ハードコードだった結線の宣言化)+ **時間持続 Mode(f−1,m) → Mode(f,m)(ヒステリシスの
     PSL 化)**+ 既定 prior(quiet / unknown / grouped)。role は 6 語彙全てに発火経路を持つ
     (supreme2 で構造的に出力不能だった source_human / source_object を含む)。
   - **結合 MAP 推論**: シナリオ内全フレーム × 3 層(mode 9 + role 6 + rel 4)の開述語を
     HL-MRF(hinge エネルギー・p=1)として同時最適化。射影劣勾配降下(層ごとの単体射影・
     ステップ 0.20/√(1+0.15t)・最大 160 反復・変化量 1e-3 未満で決定的早期終了)。
   - **学習**: 構造化パーセプトロン(E(GT 割当) − E(MAP 解) の劣勾配)でルール重み(非負
     クランプ)と MLP を同時更新。GT が語彙外(uncertain 等)のフレームは該当ブロックを
     MAP 値で中立化。決定的(固定順・full 更新・乱数なし)。
2. **core.py の結線**: strict OFF のときのみ `_run_one_scenario_neupsl` に分岐し、T2 を
   NeuPSL のシナリオ一括推論で決める。quality/risk/t1/scene は OFF 経路と同一の式・順序で
   計算(`_neupsl_prepass`)。T3 は同一コードのまま、窓に入る mode 列が NeuPSL 出力になる
   (下流効果として値が変わり得る)。**strict ON(既定)は従来ループを一切変更しない**。
3. **fit_supreme に T2 学習を統合**: train から決定的 stride で最大 800 シナリオを学習
   (6 epochs・実行時間予算による)、最大 400 シナリオの train acc で **≥ガード**(学習が事前重みに負けたら
   事前重みを採用)。`SupremeParams.t2`(既定 None=事前重み)を追加。
4. **テスト**: `test_F020_neupsl.py`(単体射影・決定性・危険→emergency と層間整合・学習の
   決定性と非劣化・持続ルールの接地数)を追加。`test_Fbase001_strict_gate.py` の OFF T2
   3 テストは「OFF = NeuPSL 経路」の期待値に更新。他のテストは無変更。

## 検証(2026-07-16)

- strict ON 経路: coverage_v3/eval 40 シナリオで supreme2 の予測と**全層完全一致**(0 差分)。
- strict OFF 経路: T2 以外の 4 層(risk/t1/quality/scene)が supreme2 の OFF(params=None)と
  **完全一致**(640/640 セル)。2 回実行の完全一致(決定的)。
- 学習パイロット(train 300 × 2 epochs): T2 micro acc 0.604(学習)vs 0.367(事前重み)。
- 全量 A/B(coverage_v3: train 800×6ep で学習 / eval 8,600・41,810 フレーム・strict OFF):
  | 層 | supreme2 | supreme3 事前重み | supreme3 学習後 | 差(s3学習 − s2) |
  |---|---:|---:|---:|---:|
  | t2_mode | 0.6637 | 0.3431 | 0.5574 | −0.1063 |
  | t2_role | 0.6067 | 0.5326 | 0.5326 | −0.0741 |
  | t2_relation | 0.5851 | 0.0757 | 0.3977 | −0.1875 |
  | t3(下流効果) | 0.4733 | 0.2723 | 0.4339 | −0.0393 |
  | 8層平均 | 0.6464 | 0.5013 | 0.5955 | −0.0509 |
  T2 以外(risk/t1/quality/scene)は supreme2 と全フレーム完全一致(不変条件の全量実証)。
  学習は事前重み比で大幅に効く(≥ガードも学習 0.5575 vs 事前 0.3561 で学習を採用)が、
  supreme2 の手調整ルールには T2 全層で届かなかった。「この GT 体系では、正しく調整された
  固定ルールが小規模学習より強い」という本プロジェクトの発見(T3・ADR 0052)を、
  本来型 NeuPSL でも三たび追認する結果である。

## 学習レシピの追加調整(2026-07-16・同日)

損失関数まわりの調整として、(a) **loss-augmented 推論**(学習時の MAP を E − 0.8·Δ(y, GT) で解き、
最も紛らわしい違反構成に対して更新する構造化ヒンジ化)、(b) **層別損失重み**(mode 1.6 / role 1.2 /
rel 1.6)、(c) エポック毎の学習率減衰(1/√ep)、(d) 学習予算の増額(2,000 シナリオ × 10 epochs・
チェックポイント方式)を導入した。eval 全量での効果:

| 層 | 調整前(800×6・マージン無) | 調整後(2,000×10・マージン有) | supreme2 |
|---|---:|---:|---:|
| t2_mode | 0.5574 | 0.4314 | 0.6637 |
| t2_role | 0.5326 | **0.6929** | 0.6067 |
| t2_relation | 0.3977 | 0.5599 | 0.5851 |
| t3(下流) | 0.4339 | 0.3524 | 0.4733 |
| 8層平均 | 0.5955 | 0.6099 | 0.6464 |

T2 の micro 平均は 0.496 → 0.561 に改善し、**role は全システム最高(supreme2 +0.086)**、relation も
ほぼ追いついた。一方でマージン学習は mode を悪化させ(0.557 → 0.431)、mode を窓入力とする t3 が
連動して低下する明確なトレードオフが観測された。層別マージン(mode のみ 0)の検証はファミリ分離
検証器の整備が前提として残課題。なお本節のレシピ比較は eval の実測を参照して選択しており、
厳密な運用ではファミリ分離のモデル選択検証を挟むべきである(既知の手続き上の注記)。

## 帰結と限定

- ヒステリシス・層間結線・既定ラベルが**すべて宣言的ルール+学習可能な重み**になり、
  「何を知識として与え、何を学習させたか」が RULES 一覧で監査可能になった。
- GT は規則生成のため、学習が獲得するのは「仕様規則への汎化」であり能力の主張には
  従来どおり独立ラベラ評価が必要(ADR 0049 の規律を継承)。
- MAP は凸緩和の劣勾配法であり、反復上限内での近似解(決定的)である。
