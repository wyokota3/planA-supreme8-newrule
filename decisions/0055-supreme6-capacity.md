# ADR 0055-s6: supreme6 — ルール不変のまま述語容量と学習予算を拡大

- 状態: 採用 / 日付: 2026-07-17 / 基点: planA-supreme5@master(60fcd59)
- 制約: 論理ルールは一切追加しない(25本+負事前19は supreme4/5 と同一)。

## 決定
ニューラル述語の隠れユニット H=3→5(学習パラメータ 176→258)、事前学習 250→400歩、
基礎9+bilevel 3 の12エポック、推論反復 160→200。他は supreme5 と同一。
