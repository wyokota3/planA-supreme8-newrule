## 受け入れ条件・規則要件の実現状況

### SPEC F-011-1（正式受け入れ条件）: F-013 の封印評価で Quality regime の項目別対比が測定・報告される（baseline 超えは成功目標）

**実現箇所**: F-011 単体スコープ外。ADR 0014「影響」節（`decisions/0014-f011-quality-recalibration.md:70`）が「受け入れ条件 F-011-1（F-013 で項目別対比が測定・報告）は F-013 で測る。F-011 単体は規則の正しさを固定」と明記。

**コメント**: 「baseline 超え」は ADR 0013（`decisions/0013-u1-improvement-allocation.md:53`）で合否ゲートでなく成功目標と再分類済み。F-011 の done 判定をこの条件で阻害しないのは妥当。

以下、ADR 0014 決定3 の優先順位チェーンを規則要件 R1〜R6 に分解して全数検証する。

### R1: branch1 — h_q < 0.25 → BLOCK（旧 BLOCK）

**実現箇所**: `src/supreme/quality.py:50-51`

**コメント**: ADR 0014 決定3（`:48`）と一致。テスト `tests/test_F011_classify_rule.py:89-94`（h_q=0.001 → BLOCK、計測 h_q≈0.0014 の悲観群相当）で固定。

### R2: branch2 — h_q < 0.40 ∧ vol > 0.05 → BLOCK（旧 早期BLOCK・本データ不作動・構造保持）

**実現箇所**: `src/supreme/quality.py:52-53`

**判定**: 実装済
**コメント**: ADR 0014 決定3（`:49`）と一致。論理積（`and`）・閾値（0.40 / 0.05）・不等号（`<` / `>`）が ADR 表記どおり。本データでは不作動（vol は全210フレームで 0.0058〜0.0099・ADR 0014 `:19`）だが faithfulness のため構造保持という決定2（`:38`）に沿う。なお R1（h_q<0.25→BLOCK）が先行するため branch2 が独立に効くのは 0.25≤h_q<0.40 ∧ vol>0.05 の領域のみ。本データに該当点はなく、専用テストはない（後述テストカバレッジ参照）。

### R3: branch3 — h_q < 0.55 → BLOCK（旧 DEGRADED → v1.4 BLOCK）。厳密 `<`（0.55 ちょうどは抜けて DEGRADED へ）

**実現箇所**: `src/supreme/quality.py:54-55`
```python

```
**判定**: 実装済
**コメント**: 不等号が**厳密 `<`** であり、観点指定どおり「0.55 は DEGRADED に抜ける」を満たす。境界の符号化を3点で確認:
- h_q=0.549 → BLOCK（`tests/test_F011_classify_rule.py:105-110`）
- h_q=0.55 → DEGRADED（`tests/test_F011_classify_rule.py:117-123`。branch3 を抜け、GOOD ゲートも満たさず branch5 へ）

### R4: branch4（GOOD ゲート再較正）— h_q ≥ 0.93 ∧ vol < 0.01 → GOOD（旧 0.94 から 0.93 へ再較正）

**実現箇所**: `src/supreme/quality.py:56-57`
```python

        return GOOD
```
**判定**: 実装済
**コメント**: 観点指定の最重要点を全て満たす。
- ゲート閾値が **0.93**（0.94 ではない）。ADR 0014 決定2（`:34,36`）の再較正値と一致。`0.94` というリテラルはコード本体（`:50-57`）に存在しない（docstring 内の説明 `:46` の「再較正 0.94→0.93」表記のみ）。
- ゲート不等号が **`>=`**（h_q=0.93 ちょうどを GOOD に含める）。テスト h_q=0.93,vol=0.009 → GOOD（`tests/test_F011_classify_rule.py:34-40`）で下端含むことを固定。

- 論理積が **`and`**（両条件 AND）。h_q≥0.93 ∧ vol<0.01 を両立する h_q=0.95,vol=0.005 → GOOD（`tests/test_F011_classify_rule.py:151-156`）。

## スコープ遵守（観点3・ADR 0014 決定1・決定4）

**判定**: 適合

- **観測式/HGF（h_q/vol 生成）を実装していない**: `classify(h_q, vol)` は h_q/vol を**引数で受け取る**のみ（`src/supreme/quality.py:36`）。内部生成の痕跡なし。`hgf` / `sigma1` / 観測式 β/τ 等のコードは存在しない（grep 一致は docstring `:5` の「観測式+HGF は F-011 スコープ外」という除外宣言のみ）。契約テスト `tests/test_F011_contract_surface.py:59-70` が「(h_q,vol) を引数で受け取る＝内部生成していない」を固定。ADR 0014 決定1（`:29-32`）に適合。

## オーバー実装の検出（観点4）

**判定**: なし（仕様にない実装は検出されなかった）

- **入力範囲外処理の追加なし**: h_q∉[0,1]・vol<0 等への特別扱い（clamp/例外/警告）は実装されていない。docstring `:19-20` が「入力範囲外の特別扱いは持たない（契約に明文なし・ADR 0014 スコープ外）」と明記し、コードもそのとおり（`:50-58` は素の比較のみ）。これはオーバー実装の**回避**として妥当。
- **学習なし**: モデル・パラメータ学習・データ読み込みのコードなし。ADR 0013（`:36`）の「quality は学習しない（param 予算を消費しない）」に適合。

- **stdlib のみ**: サードパーティ依存ゼロ（インポートは `from __future__ import annotations` のみ・`:24`）。
- **他モジュール非改修**: `quality.py` は datagov/sealset/augment/guard/harness を import しない（`:24` 以外に import 文なし）。`src/supreme/__init__.py:6-14` への quality 登録は ADR 0006 で予定済みの公開構成であり改修にあたらず、他モジュールの実体には触れていない。

## テストカバレッジ

### テストされている振る舞い
- GOOD ゲート再較正境界: 0.93→GOOD / 0.929→DEGRADED / 0.94→GOOD（`test_F011_classify_rule.py:34-56`）
- 再較正効果（+8件代表）: 0.935→GOOD（`:63-69`）
- 副作用ゼロ境界: 0.925→DEGRADED（`:76-82`）
- BLOCK 域（R1/R3）: 0.001→BLOCK / 0.3→BLOCK / 0.549→BLOCK（`:89-110`）
- BLOCK/DEGRADED 境界（R3 厳密 `<`）: 0.55→DEGRADED（`:117-123`）
- DEGRADED 中域（R5）: 0.70→DEGRADED（`:130-135`）
- GOOD ゲートの vol 条件（R4）: 0.95,vol=0.02→DEGRADED / 0.95,vol=0.005→GOOD（`:142-156`）
- 決定性（2回呼び出し同一・代表9点）（`:163-185`）
- 契約面: classify 公開・(h_q,vol) 引数・v1.4 定数公開と値一致・3クラスのみ返す（`test_F011_contract_surface.py:37-101`）

### テストされていない振る舞い
1. **branch2（R2）の独立発火**: 0.25≤h_q<0.40 ∧ vol>0.05 → BLOCK を branch2 自身が決める領域の専用テストがない。テスト `:142-148`（h_q=0.95,vol=0.02）は GOOD ゲート側の vol 条件であって R2 ではない。ただし R2 は ADR 0014 計測で本データ不作動（一度も発火しない・`:25`）であり、faithfulness のための構造保持。挙動契約（ADR 0014 `:56`）はこれを「実装裁量で簡約可」としており、未テストでも**仕様違反ではない**。リスクは限定的（R1 が先行し、該当領域に本データ点が存在しない）。
2. **入力範囲外（h_q∉[0,1]、vol<0、NaN）**: 契約に明文がなくテストもない。docstring が「特別扱いを持たない」と宣言済みで、未定義動作を仕様化していない点は一貫。スコープ外。
3. **branch1 と branch3 の境界 h_q=0.25 ちょうど**: 0.25→（R1 不成立 0.25<0.25 偽 → R3 で 0.25<0.55 真 → BLOCK）で結果は BLOCK だが、R1/R3 のどちらが効くかの境界点テストはない。最終ラベルは BLOCK で変わらないため挙動契約上の欠落ではない（R1 と R3 はともに BLOCK を返すため観測不能な内部境界）。

いずれも ADR 0014 のスコープ・挙動契約（`:55-56`）の範囲内で、done を阻害する欠落ではない。
