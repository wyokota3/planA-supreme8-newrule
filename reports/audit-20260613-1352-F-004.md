## 受け入れ条件の実現状況

### F-004-1: 同一入力・同一指標定義で測定結果が決定的（ハーネス自体が乱数で揺れない）

**実現箇所**: `src/supreme/harness.py:141-182`（`score`）/ `:94-134`（`ScoreResult`）/ `:56-87`（指標定義）

決定性の構造的担保:
- 乱数・時刻 API 不在。import は `math`/`dataclasses` のみ（`harness.py:29-30`）。`random`/`time`/`datetime`/`uuid` への参照は全文に皆無。
- 採点は整数カウント `correct`/`nonnull` の加算のみ（`harness.py:166,178,180-181`）。浮動小数は最後の `correct / nonnull`（`:118,131`）と `sum/len`（`:134`）のみで、累積順序依存の誤差が入らない。
- 層走査順は `metric_spec.scored_layers`（タプル・固定順 `_CANONICAL_SCORED_LAYERS` `:56-65`）。`MetricSpec` は `frozen=True`（`:68`）。
- `check_reproduction` の項目走査も `sorted(set(...) | set(...))`（`harness.py:244,270`）で dict 反復順序非依存。

**ADR 0012 決定の符号化**:
- 決定A（micro global pooling・完全一致・NA分母除外・8層単純平均）: `score` 二重ループが全シナリオ×全フレームをプールして層別カウンタに加算（`harness.py:168-181`）。完全一致は `view.get(layer) == gt_label`（`:179`）。NA除外は `if gt_label is None: continue`（`:174-177`、分母 `nonnull` 加算前に continue）。総合=8層単純平均は `overall()`（`:120-134`）。
- 決定B（risk_tier 短尺T0特例NA除外なし）: `score` に層別の特例分岐が一切ない。risk_tier も他層と同一経路で `gt is None` のみ除外（`:174-181`）。テスト `test_F004_1_risk_tier_no_short_t0_special_exclusion`（deterministic_scoring.py:194-208・acc=4/5=0.8）で固定。
- 決定C（Anomaly 採点外）: `_CANONICAL_SCORED_LAYERS`（`:56-65`）に Anomaly が無く、`score` は `scored_layers` のみ走査（`:172`）。trace に Anomaly を混入させても走査されない。テスト `test_F004_1_anomaly_not_in_scored_layers`（deterministic_scoring.py:215-233）で固定。
- 決定D（補助21指標を公式採点に混ぜない）: `ScoreResult` は `layer_score`/`overall` のみ公開、補助指標 API なし。テスト `test_F004_auxiliary_metrics_separate_from_official_score`（contract_surface.py:123-144）で top2_acc/KL/range_mae/mae が layers に無いことを固定。
- 決定E（t1_state 4クラス）: harness は採点語彙を列挙せず「GTに出たラベルと完全一致」で採点する設計（語彙非依存）。決定E は GT 側の性質であり、フィクスチャ `trace_t1_state_four_classes`（fixtures_harness.py:211-235）が idle/approach/pass/depart を与えて acc=3/4 を検証。

**判定**: 実装済。決定性は「乱数不在」と「整数カウント＋固定順走査」で構造的に担保。micro/macro の取り違えなし。

### F-004-2: T3 再現判定（2回流し・連続値 ε 内・分類完全一致）

**実現箇所**: `src/supreme/harness.py:202-282`（`check_reproduction`）

- ε 式: `threshold = eps_abs + eps_rel * max(abs(a), abs(b))`（`harness.py:255`）。ADR 0002（U5a）に一致。
- 境界（等号）: `if abs(a - b) > threshold:` で**厳密 `>` のときのみ mismatch**（`:256`）。等号は再現側（`≤`）。テスト t3_reproduction.py:144-157 で固定。
- 相対項: テスト t3_reproduction.py:64-77（a=1e6 で差0.4を再現OK）で `max(|a|,|b|)` が効くことを固定。
- 負値・ゼロ近傍: `abs()` 使用。ゼロ近傍は `eps_abs=1e-9` の絶対項が下支え。
- 分類は完全一致（ε 不使用）: `if va != vb:`（`:273`）。
- mismatch の項目特定: 各 mismatch dict に `item`/`kind`/`frame_index`（`:246-251,257-265,274-280`）。
- 判定の決定性: 項目走査 `sorted`（`:244,270`）。テスト t3_reproduction.py:177-185 で固定。
- フレーム数不一致・項目欠落も再現失敗扱い（`:230-235,245-251`）。

**判定**: 実装済。ε 比較は厳密 `>` で境界を再現側に含め SPEC・ADR 0002 の `≤` と整合。

## 重点検査（実装者の裁量判断と仕様の整合）

### A. 全null層（nonnull=0）の扱い — 最重点

**実装**: `layer_score` は `nonnull==0` で `math.nan`（`harness.py:116-118`）。`overall()` は `nonnull==0` の層を `continue` でスキップし採点できた層のみ平均（`:127-134`）。

**ADR 0012 決定A との突合**: 決定A は「総合 = 8層 global acc の単純平均」。全null層を除外すると総合が7層平均になり、文言と厳密一致しない。

**評価**:
- (a) テスト許容: 許容している。`test_F004_1_all_null_layer_does_not_crash`（deterministic_scoring.py:173-187）は「0除算で落ちない」「他層が 1.0」のみ検証し、全null層を含む overall() を assert しない。フィクスチャ docstring（fixtures_harness.py:150-152）も「分母0の層の表現は実装裁量」と明記。除外方式を禁止していないが正の固定もしていない。
- (b) 実害: 本採点データ（catalog 1.4.0・210フレーム）は全GT層が非null（ADR 0012:34 / SPEC.md:428）。実運用 trace で全null層の発生経路が無く実害は顕在化しない。
- (c) あるべき扱い: 実装の除外方式は「採点できた層だけで平均」という穏当な縮退で 0除算回避・他層非波及という fixtures 要求を満たす。ADR 0012 は当該縁ケースを明文化しておらず、実装の除外は ADR への明確な逸脱ではなく沈黙の裁量埋め。

**判定（全null層）**: ADR 0012 への逸脱とは断定しない。done のブロッカーにはしない（実運用で発生経路なし＋テストが除外方式を禁止せず＋ADR が当該縁を未規定）。F-013（同一土俵比較）で全null層が起きうるなら ADR で明文化すべき。

### B. micro と macro の取り違え

取り違えなし。`score` はシナリオ単位の中間平均を作らず全シナリオ×全フレームを単一カウンタにプール（`:166-181`）してから `correct/nonnull`。テスト `test_F004_1_micro_not_macro_global_pooling`（deterministic_scoring.py:95-111）が micro=0.6 を要求し macro=0.75 を明示否定。

### C. NA除外の網羅性・キー不在の堅牢性

- gt 側 NA: `gt.get(layer)` で `None` なら除外（`:174-177`）。層キー不在も `.get` が `None` を返し分母不算入。
- view 側欠損: `view.get(layer)`（`:179`）。view に層キーが無ければ `None`、gt 非null なら `None == gt_label` は `False`＝誤答として算入（妥当）。KeyError で落ちない。
- view 側欠損を正答にカウントしないことの直接 assert は無い（コード上は誤答になる）。カバレッジ欄に記録。

### D. ε 比較の正しさ

F-004-2 欄で詳述。厳密 `>` で mismatch・境界は再現側・相対項有効・`abs()` で負値とゼロ近傍に対応。両側境界テストあり。破綻なし。

### E. 決定性の担保（反復順序・累積順序）

- 層走査: タプル固定順。項目走査: `sorted`。集合反復: `sorted` でラップ。浮動小数は整数加算後の1回除算のみ。dict 反復順序が結果に影響しない。
