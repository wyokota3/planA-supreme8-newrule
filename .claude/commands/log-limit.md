利用制限(5時間制限 または 週次制限)に当たったことを `reports/worklog.jsonl` に記録してください。

引数(任意): $ARGUMENTS （例: `weekly F-003 step5` のように、制限の種類と作業中だった機能/ステップ。未指定なら現在の作業状況から推測し、不明な点はユーザーに確認する）

## やること

1. 制限の種類を判定(`5h` / `weekly`)。引数になければユーザーに確認。
2. 作業中だった機能ID・ステップを特定(直近の git log や status.json の wip 機能から推測してよい。曖昧ならユーザーに確認)。
3. `reports/worklog.jsonl` に以下の形式で1行追記する(ファイルが無ければ作成):

```json
{"ts":"<ISO8601 現在時刻>","event":"limit_hit","limitType":"5h|weekly","feature":"F-XXX","step":"<停止したステップ>","note":"<任意メモ>"}
```

## 完了後

- 記録した内容を表示する。
- これまでの `limit_hit` の累計回数を数えて伝える。
- 「`/report-effort` で、この制限到達ログを含む昇格エビデンスを生成できます」と案内する。
