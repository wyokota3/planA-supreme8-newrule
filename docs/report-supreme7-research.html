NS-EPI L04 · planA-supreme7 · 判断ルールは固定したままの徹底調査 · 2026-07-17

supreme7 研究レポート — この AI は「何で動いていて」、結局どこまで上がるのか

supreme4〜6 で作った T2(音の場面を「様相 mode・主 role・関係 relation」の3つで解釈する部分)を、 今回はスコア競争ではなく研究対象として調べました。やったことは単純で、 「部品を1つずつ外して壊れ方を見る」「満点が原理的に取れない部分を数える」「答えを磨く回数や練習量を変えてみる」の3つです。 判断ルール(25本)は一切追加していません。

このレポートで使う言葉(4つだけ)
見張り役(センサー) — 入力から「会話っぽさ」「呼びかけっぽさ」などの度合いを 0〜1 で出す小さな学習部品。9個あります。正式には「ニューラル述語」。
判断ルール — 「危険なら緊急のはず」のような、見張り役の出力を結論につなぐ 25 本の規則。重みは学習で調整されますが、本数は固定です。
個別レッスン — 本番の練習(全体学習)の前に、見張り役だけを正解データで先に鍛えること。正式には「事前学習」。
集計方法 — 複数のルールが違う結論を推すときのまとめ方。「勝者総取り」か「票の重さで按分」か(正式には p=1 と p=2 のヒンジ)。
先に結論(やさしい5行)
  1. この AI の実力は、ほぼ「見張り役への個別レッスン」と「按分方式の集計」の2つで出来ていました。前者を止めると mode と role が崩壊し、後者を勝者総取りに変えると relation が崩壊します。残りの工夫は保険でした。
  2. mode と relation には「答えの選択肢に無い正解」が約15%ずつあり、そこは何をしても取れません(満点の上限が 0.85 前後)。role には上限がなく、実際ほぼ満点圏(0.970)です。
  3. このシステムには急所が1つあります。「呼びかけっぽさ」の見張り役(AddrEv)を止めると、relation はほぼ全滅します。
  4. 答えを磨く回数は 60回で十分でした(今は200回=3倍のムダがあり、その分速くできます)。どこから計算を始めても答えは同じになることも確認しました。
  5. 練習データを増やす価値があるのは実質 role だけです。mode と relation は200シナリオで頭打ちになります。
結局どこまで上がるのか現在地 → 理論上限 → 現実的な到達目安

いちばん知りたいのはここだと思うので、8層全体の平均スコアで示します。読み方は「現在 0.687。 判断ルールを増やさない限り、どんなに学習を頑張っても約 0.75 が天井。現実的に狙えるのは 0.70〜0.72 あたり。 それ以上はルールと語彙の追加(supreme8 以降の課題)が必要」です。

調査1部品を1つずつ外して、何が本当に効いているのか調べた

7つの工夫を1つずつ外して同じ条件で学習し直し、成績がどう変わるかを見ました。赤字が「外すと壊れる」箇所です。

調査2満点が取れない「選択肢の壁」を数えた(全41,810フレーム)

正解データには、この AI の答えの選択肢に存在しないラベルが混ざっています(mode の「不確か」、relation の「離脱中」「無関係」)。 その分は何をしても不正解になるので、まずその壁の位置を正確に測りました。

調査3急所さがし — 部品を1個ずつ止めて、どれだけ困るか

完成品から見張り役やルールを1個だけ止めて、成績の落ち幅(3層合計)を測りました。落ち幅が大きいほど「その部品に頼っている」ことを意味します。

調査4・5答えを磨く回数と、練習データの量

磨く回数: この AI は答えを出すとき、内部で答え候補を少しずつ磨いていきます。実験の結果、 20回では磨き足りず(mode が −0.157)、60回で完成し、それ以上は300回まで増やしても小数第4位まで変わりませんでした。 現在の設定は200回なので、3倍のムダ=3倍の高速化余地があります。また、磨き始めの状態をどう変えても最終的な答えは 100% 同じになることを確認しました(答えがブレない仕組みが機能している証拠です)。

まとめ次にやるべきこと(ルールは増やさずに)

この研究の答えを一言でいうと、「この AI は個別レッスン済みの少数の見張り役と、それをつなぐ少数の強いルールで動いており、 現在 0.687、学習の工夫で 0.70〜0.72、ルールを増やさない限りの天井が約 0.75」です。 次の一手は優先順に、①呼びかけ見張り役の「お手本」の作り直し(調査1の逆転現象が示す一番の伸びしろ。relation の +0.27 の一部が狙えます)、 ②急所の分散(見張り役の入力を増やして AddrEv 一点依存を解消)、③磨く回数を 200→60 に減らして浮いた計算力を練習量に回す、の3つです。 その先の 0.75 超えを目指す時点で、初めてルールと選択肢の追加(supreme8)が必要になります。

注意書き: 採点に使う「正解」は人間の判断ではなく固定の規則から機械的に作られたものなので、 ここでの数字はすべて「その規則にどれだけ合わせられるか」の測定です。人間の感覚と合うかどうかは、別途の人手評価が必要です。 また調査1・3・4・5 は全条件共通の評価用サンプル(1,200シナリオ)での比較で、全量での絶対値とは水準が異なります。
