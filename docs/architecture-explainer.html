NS-EPI supreme8 アーキテクチャ解説

環境音から状況を読み取り、8 層の EPI を出力する決定的エンジン supreme8 の仕組みを解説します。中核は、T2 の 3 層（場の様相 mode・音源の正体 role・関係 relation）を本来型 NeuPSL（ニューラル述語と論理ルールと結合 MAP 推論を組み合わせた枠組み）で解くところにあります。あわせて、能力評価の土俵 situations_v1（strict OFF・別土俵）で測った結果も示します。

この資料で学べること
  • supreme8 が入力契約を検証してから 8 層の EPI を返すまでの処理順を説明できるようになります。
  • PSL の連続値論理、ニューラル述語、接地、エネルギー最小化、結合 MAP の関係を手計算から理解できるようになります。
  • 本物の 41 ノード・74 配線をたどり、観測が 29 本のルールと 22 個のターゲット値へどう伝わるかを説明できるようになります。
  • 実測トレースと学習図を使い、推論時のデータ経路と学習時の教師信号を区別できるようになります。
  • situations_v1 の KPI を strict OFF、world-first GT、rejection_acc という測定条件と一緒に解釈できるようになります。

第1章　supreme8 の全体像

この章のゴールは、入力、前処理、NeuPSL、T3、出力、評価という 6 段の役割を区別し、supreme8 の処理を端から端まで説明できるようになることです。

supreme8 は、環境音の時系列から状況を読み取り、8 つの層（risk_tier / t1_state / t2_mode / t2_role / t2_relation / t3_hypothesis / quality_regime / scene_regime）を出力する決定的なエンジンです。同じ入力からは必ず同じ出力が出るように設計されています。

このエンジンの中心にあるのは、T2 の 3 層（mode・role・relation）を本来型 NeuPSL で解く部分です。NeuPSL は次の 3 つの部品からできています。1 つ目は、生の特徴を 0〜1 の軟らかい真理値に直すニューラル述語です。2 つ目は、Łukasiewicz 緩和（論理式を連続値で扱えるようにする方法）にもとづく重み付きの論理ルールで、いまは 本あります。3 つ目は、シナリオ内の全フレームと 3 層をまとめて最適化する結合 MAP 推論（HL-MRF）です。T2 以外の 6 層は、prepass（risk・t1・quality・scene を観測式・HGF・状態機械で求める前処理）と T3 統合が受け持ちます。

今回の主役である N3（PRIMARY）構成では、全 8 層をならした pooled overall が でした。層ごとに見ると、quality（）・t1（）・role（）が高く、mode（）と t3（）が低いという傾向でした。第2章で 8 層を見渡し、第3章で NeuPSL を手計算し、第4章から本物の配線、実測トレース、学習へ進みます。

このページに出てくる数値は、すべてページ内に埋め込んだ results.json 相当のデータから機械的に計算しています。手で書き写した数値はありません。

第3章　手計算で学ぶ段階的 NeuPSL 入門

この章のゴールは、小さなおもちゃの例を使い、PSL、ニューラル述語、接地、エネルギー最小化を一つずつ積み上げ、本物の配線図を読む準備を整えることです。

この章の数値は仕組みを理解するために単純化したものであり、supreme8 の実データではありません。各ステップの最後に「本物では」という橋渡しを置き、第4章の 41 ノード・74 配線へ接続します。

ステップ1　PSL は論理ルールを連続値で扱います

PSL では、真偽を 0 または 1 に限定せず、0 から 1 までの述語の真理値として表します。含意 A → B の Łukasiewicz 違反量は max(0, I(A)−I(B)) です。証拠 A が強いのに結論 B が弱いほど、ルールを強く破ったと判断します。図を見てください。

ルールは if 文ではありません。

PSL のルールは条件が成立した瞬間にラベルを確定する分岐ではありません。各ルールは候補解へ連続値の罰を加え、すべての罰を合わせた結果として最終解が決まります。

ステップ2　ニューラル述語は観測を真理値へ翻訳します

生の観測だけでは「会話らしさ」や「遠さ」のような中間概念を直接表せません。ニューラル述語は、観測ベクトルを小さな MLP に通し、0 から 1 までの真理値へ変換します。図では、実装と同じ tanh と sigmoid の順序を 1 ユニットに単純化しています。

ステップ3　接地はルールの型を各フレームへ展開します

接地とは、変数を含むルールのテンプレートへ具体的なフレームを代入する操作です。図では、1 本のテンプレートが 2 フレームへ適用されるため、独立した 2 個のポテンシャルへ増えます。

ステップ4　MAP はエネルギーが最小の候補を選びます

MAP 推論では、すべての接地ポテンシャルと事前項を足したエネルギーを最小にする候補を選びます。図では、Emergency と Quiet の和を 1 に保った 2 候補を比べます。

結合 MAP で三つのヘッドを同時に解くのでしょうか。

mode、role、relation を別々に決めると、emergency なのに音源が会話であるような不整合を後から修正する必要があります。結合 MAP は層間ルールと時間持続ルールを同じエネルギーに入れるため、三つのヘッドと全フレームの辻褄を一度に評価できます。

この章のまとめ

PSL のルールは連続値の違反量を二乗ヒンジのエネルギーへ変換します。

ニューラル述語は観測を 0 から 1 までの真理値へ翻訳し、接地がテンプレートを具体的なポテンシャルへ展開します。

MAP 推論は全ポテンシャルの合計エネルギーを最小にする候補を選びます。

確認問題
問1　Siren=0.9、Emergency=0.3 のとき、重み2の二乗ヒンジ寄与はいくつですか。

違反量は 0.60、二乗ヒンジは 0.36 なので、エネルギー寄与は 2×0.36=0.72 です。

問2　1 本のルールテンプレートを 2 フレームへ適用すると、ポテンシャルはいくつできますか。

2 個できます。各フレームを代入した接地が 1 個ずつ生成されます。

最終的に何と比較されるのか — 3つの分類問題

Mode、Role、Rel は、採点上は互いに独立した三つのフレーム単位分類問題です。エンジンは各フレームについて、Mode では場の様相を、Role では音源の正体を、Rel ではユーザーや周囲との関係を一つずつ選びます。ここでいう「独立」は GT との比較と採点を層ごとに分けるという意味であり、推論時に三つを別々に解くという意味ではありません。

分類問題各フレームで分類する対象src/supreme/neupsl.py の正確な語彙
Mode（10 クラス） その場がどのような様相にあるかを分類します。 conv_request, conv_ongoing, surround_activity, forward_caution, side_rear_caution, alert_required, emergency, quiet_standby, env_change, uncertain
Role（6 クラス） 主な音源が何であるかを分類します。 source_speech, source_vehicle, source_alarm, source_human, source_object, unknown
Rel（6 クラス） 音源がユーザーや周囲とどのような関係にあるかを分類します。 addressing_user, near_user, approaching, grouped, departing, unrelated

結合 MAP とは — 全部を同時に決める仕組み

「結合」とは、フレームも層も別々に決めず、シナリオ全体を一つの最適化問題として同時に解くことです。変数は全フレーム×値であり、eval の平均 フレームのシナリオでは約 変数になります。

図7cでは、二つのフレームと Mode・Role の二層だけを抜き出し、三種類のルールが違反コストの綱として変数を結ぶ様子を示します。

結合 MAP は E(y)=Σ w×違反² を全変数について最小化し、射影劣勾配法を約 200 反復する決定的な手順で、各層の値を確率単体へ戻しながら更新します。最適化が終わると、各フレームの各層で argmax を取り、Mode、Role、Rel の三つのラベルを確定します。

結合をどのようにイメージすればよいでしょうか。

結合 MAP はクロスワードパズルに似ています。1 マスずつ独立に埋めるのではなく、縦と横の答えが同時に整合するように全マスを決めるのと同じように、全フレームと全層の辻褄が合う解を探します。これは計算内容を単純化したおもちゃの例ではなく、「結合」の考え方をつかむための比喩です。

MAP は述語の出力を後処理で微修正するのでしょうか。

MAP はニューラル述語の出力を後処理で微修正するものではありません。述語値は固定の証拠として入り、ターゲット 22 値の側を全体整合が取れるまで動かします。

NeuPSL は後処理ではありません。

NeuPSL はニューラルモデルが出したラベルを最後に整えるだけの処理ではありません。ニューラル述語の真理値、観測原子、論理ルール、層間整合、時間持続を一つのエネルギーへ入れ、T2 のラベルそのものを結合 MAP で生成します。

学習レシピ（4 段のパイプライン）

T2 の各層は、次の 4 段のパイプラインで学習されます。上の学習図の 3 段に対応し、②の中で二乗ヒンジと指数勾配を分けて数えると 4 段になります。段ごとに役割が違い、前の段の成果を次の段が受け継いでいきます。

述語 MLP を先に事前学習するのでしょうか。

初期状態の MLP が意味のある真理値を出さなければ、後段の論理ルールは良い証拠と悪い証拠を区別できません。GT から作った蒸留ターゲットで述語を先に立ち上げると、構造化学習は意味のある中間概念を出発点にしてルール重みを調整できます。ADR 0056 の切り分けでも、事前学習が最大の寄与を示しました。

ADR 0056（研究世代）でわかったこと。 各要素の効きを切り分けたところ、寄与の大きさは「事前学習 ≫ 二乗ヒンジ ≫ その他」の順でした。つまり性能の源泉は、ニューラル述語をラベル蒸留で事前学習すること、そして二乗ヒンジでポテンシャル（罰の形）を整えることにあります。役割別に見ると、role は少数の述語に強く依存し、mode と relation は語彙の上限近くで学習しきれない残りが大きい、という傾向でした。

N3（PRIMARY）レシピの実測時間（results.json より）は、次のとおりです。t3/scene の学習に 秒、T2 の基礎 6 エポックに 秒、bilevel 2 エポックと ≥ ガードに 秒かかりました。≥ ガード（最大 400 練習シナリオで判定）では、学習後の精度 と事前重みの精度 を比べ、学習が事前重みを下回った場合は事前重みを採用します。これは、学習がかえって悪化させないための保険です。

結果を読むために必要な測定条件（strict OFF と監査是正の要点）。

strict OFF は必須です（strict_gt_conformance=False・ADR 0050）。strict ON（GT を導く規則 f の写し）を使うと、ADR 0049 で撤回した循環スコアが再発してしまいます。そのため能力評価では、T2 を NeuPSL の結合 MAP 経路に通します。

監査 P0 の是正を反映しています。 t3/scene 学習に使う mode 系列を、strict ON の view から strict OFF の公開 API（run_supreme_scenarios(..., strict_gt_conformance=False)）由来へ変えました（P0-2）。さらに、学習に使う非違反入力を fit の前にすべて事前検査し、誤って拒否されたもの（false reject）は学習から除外します（P0-1。今回の train_false_reject は 件でした）。

拒否は別枠で採点します。 契約に違反する eval 入力は 8 層採点の分母から外し、明示的に拒否できたかどうかだけを rejection_acc で測ります（eval では / ＝ でした）。

  • 別の土俵であることを、はっきりさせます。 situations_v1 は world-first 生成で、正解は潜在世界 W に由来します。したがって coverage 系の数値とは並べません。引用するときは、スイート名・分割・測定日をそえます。

能力評価を strict OFF で測るのでしょうか。

strict ON は GT を導く生成規則 f の写しを使うため、同じ規則で問題を作り、同じ規則で答え、同じ規則で採点する循環が起こり得ます。strict OFF では公開 API の通常推論経路を使うため、NeuPSL が観測から推論する能力を独立した world-first GT と照合できます。

第10章　限界と正直な注記

この章のゴールは、パラメータ数の既存ガード失敗、GT とモチーフの限界、MAP の近似性、世界由来 GT による構造的天井を区別し、数値を過大解釈しないことです。

既存テストの失敗について（F-015 とは無関係です）。 SupremeParams.learnable_param_count() は （NeuPSL ＋ t3 ＋ scene ）で、閾値 360 を超えています。そのため、param ≪ data を確かめる F-014-1 のガードテスト（tests/test_Phase1_learning_wiring.py）が、master 基点で既に失敗しています（ADR 0057 の新ルールで学習パラメータが増えたためです）。これは F-015 の変更をすべて退避しても再現する既存の失敗であり、F-015 自体のテストはすべて緑です。
  • GT は規則で生成されています。 そのため、学習が身につけるのは「仕様規則への汎化」です。能力を主張するには、独立ラベラ（f_blind）との照合をあわせて示す必要があります（ADR 0049 を継承）。situations_v1 は、その循環を「GT を潜在世界から直接導く」ことで構造的に避けた別土俵です。
  • モチーフには限りがあります。 train と eval は、同じ 50 モチーフの別パラメータです。最終確定の測定（seal）には、完全に新作のモチーフが必要です（これは生成器側の宿題です）。
  • MAP は近似解です。 凸緩和した問題を劣勾配法で解いており、反復の上限内で得られる決定的な近似解です。
accuracy が 1.0 未満ならバグだとは限りません。

world-first GT は潜在世界から正解を導きますが、エンジンが観測できる情報には限りがあります。さらに scene_regime では Safety Latch が働くため、潜在世界の区別を観測から常に再現できるとは限りません。この情報差による構造的天井は、実装バグとは分けて扱う必要があります。

この章のまとめ

F-014-1 のパラメータガード失敗は既存の問題であり、F-015 の能力評価とは分けて扱います。

同一モチーフの別パラメータだけでは最終的な汎化を確定できないため、新作モチーフによる seal が必要です。

MAP の近似性と観測情報の不足は、accuracy の限界を解釈するときに明示します。

巻末用語集

この付録のゴールは、本文で使った主要語を短い定義で引き直し、似た概念の役割を区別できるようにすることです。 用語は読みの五十音順に並べています。

Łukasiewicz 緩和（ウカシェヴィチかんわ）
論理演算を 0 から 1 までの連続値へ拡張する方法です。含意の違反量を max(0, I(body)−I(head)) として計算できます。
HL-MRF（エイチエル・エムアールエフ）
Hinge-Loss Markov Random Field の略です。ヒンジ損失のポテンシャルを足した凸エネルギーとして、PSL の連続値推論を表します。
エネルギー
候補解がルールや事前分布をどれだけ破るかを合計した値です。MAP 推論はこの値が最小の解を探します。
確率単体・simplex 射影
各成分が 0 以上で、同じヘッドの成分和が 1 になる集合です。射影劣勾配法は更新後の値をこの集合へ戻します。
観測原子
入力から直接得られ、MLP を通さず真理値として使う述語インスタンスです。本物の配線には 1 フレームあたり 14 個あります。
結合 MAP
複数のヘッドやフレームを別々に解かず、一つのエネルギー最小化として同時に解く方法です。supreme8 では mode、role、relation と全フレームを束ねます。
strict OFF
strict_gt_conformance=False で通常推論経路を使う評価条件です。GT 生成規則の写しによる循環を避けます。
接地
変数を含むルールテンプレートへ具体的なフレームやクラスを代入する操作です。接地ごとにエネルギーへ加わるポテンシャルができます。
述語
対象について成り立つ性質や関係を表す関数です。PSL では値を 0 から 1 までの真理値として扱います。
蒸留
教師モデルや GT から作った軟らかなターゲットを使い、小さなモデルへ知識を移す学習方法です。ここではニューラル述語の事前学習に使います。
NeuPSL
ニューラル述語と PSL の重み付き論理を組み合わせる枠組みです。supreme8 では T2 三層を結合 MAP で生成します。
ニューラル述語
観測ベクトルを小さな MLP に通して真理値を出す述語です。本物の配線では 12 個あります。
bilevel（バイレベル）
内側の MAP 推論と外側の学習目的を分けて最適化する二段構造です。N3 では Moreau 包絡にもとづく BCE 微調整に使います。
ヒンジ損失
違反がないときは 0 で、違反が正になった部分だけを罰する損失です。supreme8 は違反量を二乗する二乗ヒンジを使います。
PSL（ピーエスエル）
Probabilistic Soft Logic の略です。論理ルールを連続値へ緩和し、違反量を重み付きポテンシャルとして推論します。
負事前
証拠が乏しいクラス値がむやみに高くならないように加えるクラス別の事前項です。ルールのエネルギーと一緒に最小化します。
prepass
NeuPSL より前に入力を検証し、risk、t1、quality、scene を決める決定的な前処理です。T2 が使う特徴もここで作ります。
ポテンシャル
一つの接地ルールが候補解へ与える非負の罰です。重み、違反量、ヒンジの次数から値が決まります。
MAP 推論
Maximum A Posteriori 推論の略です。ここでは事後確率を最大にすることと等価な、エネルギーを最小にする解を探します。
rejection_acc
契約違反入力を明示的に拒否できた割合です。違反入力を 8 層 accuracy へ混ぜず、別枠で安全性を測ります。
world-first GT
観測やエンジン規則ではなく、先に定めた潜在世界 W から正解を直接導く方式です。自己採点の循環を構造的に避けます。
