先に読む用語と識別子

GT / ADR
GTは正解ラベル（Ground Truth）、ADRは設計判断記録（Architecture Decision Record）です。
N3 / PRIMARY
N3はT2を基礎6エポックとbilevel 2エポックで学習し、bilevel段でMLPを固定する構成です。本評価で主値として採用するためPRIMARYと呼びます。
T0〜T3
処理段の識別子です。L1〜L8という出力フィールド番号とは別体系です。T3の正式展開はEpisodic Predictive Insightです。T0〜T2の独立した正式展開は、本リポジトリでは確認できません。
PSL / MAP
PSLはProbabilistic Soft Logic、MAPはMaximum A Posteriori推論です。supreme8では、重み付きルールの違反エネルギーが最小になるT2三層の候補を選びます。
MLP / BCE
MLPは多層パーセプトロン、BCEは二値交差エントロピーです。MLPはニューラル述語を作り、BCEはその事前学習とbilevel微調整で使います。
F-015 / F-014-1
F-015はsituations_v1評価アダプタ、F-014-1は学習可能パラメータ数をデータ予算と照合するガードです。
QoS / Safety Latch
QoSはPSOのscene_state.QoSから読む観測品質信号です。入力契約上の単位と値域は本資料では未確認です。Safety Latchは、観測品質が崩れたときにscene出力を安全側へ制限する機構です。
接地 / ポテンシャル
接地は、変数を含むルールテンプレートへ具体的なフレームやクラスを代入する操作です。ポテンシャルは、接地された1本のルールが候補解へ与える非負の罰です。
strict OFF
strict_gt_conformance=Falseで通常推論経路を使い、GT生成規則の写しを推論へ入れない評価条件です。
world-first GT
観測やエンジン規則ではなく、先に定めた潜在世界から正解ラベルを導く方式です。

名前が対応している述語はラベルなのでしょうか。

SpeechSrcやDepEvのようにクラスと1対1に見える名前のニューラル述語がありますが、これらは固定証拠であってラベルではありません。観測原子、論理ルール、層間整合、時間持続を同じエネルギーへ入れてターゲット22値を動かし、最終ラベルは必ずターゲット原子Mode(f,c)、Role(f,c)、Rel(f,c)のargmaxで決めます。したがって、NeuPSLは述語名をラベルへ写したあとに微修正する後処理ではありません。

ニューラル述語は証拠値であり、最終ラベルではありません。最終ラベルは、ターゲット述語の層別argmaxで決まります。

最終的に何と比較されるのか — 採点を3段階で確認します

mode（場の様相）、role（音源の正体）、relation（関係）は、採点上は互いに独立した三つのフレーム単位分類問題です。エンジンは各フレームについて、それぞれ一つの最終ラベルを選びます。ここでいう「独立」はGTとの比較と採点を層ごとに分けるという意味であり、推論時に三つを別々に解くという意味ではありません。

ステップ1　PSL は論理ルールを連続値で扱います

PSL では、真偽を 0 または 1 に限定せず、0 から 1 までの述語の真理値として表します。含意 A → B の Łukasiewicz 違反量は max(0, I(A)−I(B)) です。証拠 A が強いのに結論 B が弱いほど、ルールを強く破ったと判断します。図9を見てください。

ルールは if 文ではありません。

なぜ凸最適化なのか — 全体の辻褄合わせが必ず同じ答えに着地する理由

導入として、離散の論理割当をそのまま探索する難しさから考えます。 各フレームの各ラベルを0か1だけで決めると、フレーム数とラベル数が増えるたびに候補の組み合わせが爆発します。supreme8は、Łukasiewicz緩和で各真理値を0から1までの連続値へゆるめる凸緩和を使います。この変換によって、候補を一つずつ列挙する探索問題が、連続値の凸最適化へ変わります。これは、ヒンジ損失で連続値の論理を表すHL-MRFの設計思想です。

「MAPは凸緩和の劣勾配法であり、反復上限内での近似解（決定的）である。」

ADR 0052の帰結と限定から引用しています。

結合MAPは次のように解きます。 ルールは接地されて二乗ヒンジ（p=2）のポテンシャルになり、クラス別負事前とεI（ε=0.005）のTikhonov正則化を加えたエネルギーE(y)=Σ w·max(0,I(body)−head)² + Σ(p_c+ε)y_c²を作ります。これを射影劣勾配法で、層ごとに確率単体へ射影しながら最小化します（決定的・iters=200）。時間持続t_persist_modeが全フレームを1つのMAPに束ねるため、答えは最も強い述語の丸写しではなく、シナリオ全体で最も辻褄の合う組み合わせになります。

結合 MAP は E(y)=Σ w×違反² を全変数について最小化し、射影劣勾配法を約 200 反復する決定的な手順で、各層の値を確率単体へ戻しながら更新します。最適化が終わると、各フレームの各層でargmaxを取り、mode（場の様相）、role（音源の正体）、relation（関係）の三つの最終ラベルを確定します。

直感として、一つの谷だけを持つ地形を想像します

凸なエネルギー地形には、下り始める場所が違っても目指す底が同じであるという特徴があります。非凸な地形では複数の谷があり、初期値によって別の局所解へ入る可能性があります。図16は、この違いだけを模式化しています。

仕組みとして、目的関数と制約を一つずつ凸に組み立てます

1各ルールの罰が凸になります

接地した各ルールは、ターゲット変数yに対してアフィンな違反量ℓ(y)を作り、max(0, ℓ(y))²を罰として加えます。アフィン関数に二乗ヒンジを合成したこの関数は凸です。

2重み付き和も凸のままです

29本のルールは非負重みwを持ちます。凸関数を非負重みで足しても凸なので、Σ w·max(0,ℓ(y))²も凸になります。

3二次項が最小点を一意にします

クラス別負事前のp_c·y_c²は凸二次関数です。さらに、ε‖y‖²をε=0.005で加えるため、目的関数は強凸性を持ち、厳密な最小点が一つに定まります。

4許される領域も凸になります

各フレームのmode（場の様相）、role（音源の正体）、relation（関係）は、各成分が非負で合計が1になる確率単体上に制約されます。単体は凸集合なので、二つの許される解を結ぶ線分もすべて許される解になります。

以上をまとめると、supreme8の記号推論は「凸関数を凸集合上で最小化する問題」です。したがって、局所的な最小点はそのまま大域最適であり、非凸最適化のように悪い局所解へ閉じ込められません。εIのTikhonov項が強凸性を与えるため、理論上の厳密解は一意です。

「二乗ヒンジ（p=2）とε‖y‖² Tikhonov（ε=0.005）を導入し、MAPを一意化して学習勾配を安定させる。」

ADR 0053の決定1を要約して引用しています。

1

2

初期値、処理順、ステップ幅、射影のソート順に乱数や時刻を使わないため、同じ入力と同じパラメータからは毎回同じ近似解が得られます。ただし、実装は反復上限を持つため、返す値は一意な厳密解そのものではなく、その大域解へ近づいた決定的な近似解です。

用語上の注意として、max(0,ℓ)²は継ぎ目でも一階微分が連続なC1級なので、この実装では通常の勾配を計算できます。本資料では、ADRとリポジトリが採用している名称に合わせて「射影劣勾配法」と呼びます。

ニューラル述語のMLPを学習する問題そのものは非凸です。しかし、推論時には学習済みMLPのパラメータを固定し、その出力を0から1までの証拠として受け取ります。したがって、ニューラル知覚が非凸であっても、その証拠を受け取ってmode（場の様相）、role（音源の正体）、relation（関係）の辻褄を合わせる記号側は凸に保たれます。これが、NeuPSLにおける非凸な知覚と凸な推論の分業です。

追いたいのは、ボールの道順ではなく、底の高さの変化です

図19では、難しそうに見える方法と、実際に使える方法を二つのコマで比べます。

谷底では、ボールが動ける方向に沿って地面が平らです。そのため、ボールが少しずれても、高さは一次近似では変わりません。最初に効く変化は地形そのものの上下なので、ボールを今の谷底に固定したまま、地形だけをつまみで微分してよいことになります。

この考え方を包絡定理（Danskinの定理）と呼びます。名前は難しく見えますが、要点はdV/dψ = ∂E/∂ψ(x*を固定)という一行です。ボールがどの道を通ったかを微分せず、今いる谷底で地形が上下する速さだけを測ります。

谷が一つだから、測る底が途中で入れ替わりません

谷が二つあると、つまみを少し回した瞬間に、最も低い谷が隣へ切り替わり、ボールがジャンプすることがあります。このとき、高さそのものが消えるのではなく、高さの変わり方がガクンと切り替わり、折れ曲がる点では微分が一つに定まりません。

強凸なら谷は一つなので、どの谷を測るかが途中で入れ替わりません。つまり、「強凸なら答えが一つに決まる」という一意性が、学習へ返す変化率を安定させます。これが、ADR 0053の「MAPを一意化して学習勾配を安定させる」という設計の正体です。
