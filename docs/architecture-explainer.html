先に読む用語と識別子

GT / ADR
GTは正解ラベル（Ground Truth）、ADRは設計判断記録（Architecture Decision Record）です。
N3 / PRIMARY
N3はT2を基礎6エポックとbilevel 2エポックで学習し、bilevel段でMLPを固定する構成です。本評価で主値として採用するためPRIMARYと呼びます。
T0〜T3
処理段の識別子です。L1〜L8という出力フィールド番号とは別体系です。T3の正式展開はEpisodic Predictive Insightです。T0〜T2の独立した正式展開は、本リポジトリでは確認できません。
PSL / MAP
PSLはProbabilistic Soft Logic、MAPはMaximum A Posteriori推論です。supreme8では、重み付きルールの違反エネルギーが最小になるT2三層の候補を選びます。
MLP / BCE
MLPは多層パーセプトロン、BCEは二値交差エントロピーです。MLPはニューラル述語を作り、BCEはその事前学習とbilevel微調整で使います。
F-015 / F-014-1
F-015はsituations_v1評価アダプタ、F-014-1は学習可能パラメータ数をデータ予算と照合するガードです。
QoS / Safety Latch
QoSはPSOのscene_state.QoSから読む観測品質信号です。入力契約上の単位と値域は本資料では未確認です。Safety Latchは、観測品質が崩れたときにscene出力を安全側へ制限する機構です。
接地 / ポテンシャル
接地は、変数を含むルールテンプレートへ具体的なフレームやクラスを代入する操作です。ポテンシャルは、接地された1本のルールが候補解へ与える非負の罰です。
strict OFF
strict_gt_conformance=Falseで通常推論経路を使い、GT生成規則の写しを推論へ入れない評価条件です。
world-first GT
観測やエンジン規則ではなく、先に定めた潜在世界から正解ラベルを導く方式です。

supreme8は、PSOを検査し、前処理で4層、NeuPSLで3層、T3で1層を決めます。2026-07-22のsituations_v1評価では、契約適合4,057フレームの8層マクロ平均accuracyが62.6%でした。契約違反は5/5件を拒否しました。

situations_v1は6つのsuite tagからなるworld-first GTの能力評価です。公開viewのstrict OFF経路でシナリオを測定しました。suite tagは第3章、引用条件は第6章を参照してください。

拒否結果の限界: 100%は5/5を指します。対象はframe count不一致、bad version、timestamp逆行、型破損の4種類だけです。未知の違反形式は保証しません。

候補値から最終ラベルが確定するまで — NeuPSLターゲット述語の層別最大値選択を確認します

述語名はラベルではありません。結合MAP後、mode・role・relationごとに最大ソフト値のクラス引数を選びます。以下、この層別最大値選択をargmaxと呼びます。

述語の種類個数またはファミリ推論で果たす役割ラベルとの関係
観測述語 1 フレームに 14 個あります。 入力値を固定証拠としてルールへ渡し、MAP の途中では値を動かしません。 観測述語はラベルではありません。
ニューラル述語 1 フレームに 12 個あります。 MLP が観測を読み替え、[0,1] の証拠値としてルールへ渡します。 ニューラル述語もラベルではありません。
ターゲット述語 Mode(f,c)、Role(f,c)、Rel(f,c)の3ファミリがあります。 各原子はMAPが動かす変数になり、1フレームにmode（場の様相）10個、role（音源の正体）6個、relation（関係）6個が並びます。 述語名ではなく、クラスを表す引数がラベルです。

図2では、ターゲット原子を述語名と二つの引数に分け、22 原子から三つの最終ラベルが決まるまでを示します。

クラスと 1 対 1 に対応するように見えるニューラル述語も、ラベルを直接出すのではなく、次のルールを経由して特定のクラスを押します。矢印は同一性ではなく、「証拠 → 押す先」という方向を表します。

  • SpeechSrc →（r_speech_role というルールを経由して）→ source_speech を押します。
  • HumanSrc →（r_human_role というルールを経由し、¬SpeechSrc ∧ ¬alarm という条件とともに）→ source_human を押します。
  • ObjSrc →（r_object_role というルールを経由し、¬siren という条件とともに）→ source_object を押します。
  • DepEv →（r_depev_rel というルールを経由して）→ departing を押します。
  • FarEv →（r_far_unrel というルールを経由し、¬approaching という条件とともに）→ unrelated を押します。
  • UncEv →（r_unc_mode というルールを経由して）→ uncertain を押します。
名前が対応している述語はラベルなのでしょうか。

SpeechSrcやDepEvのようにクラスと1対1に見える名前のニューラル述語がありますが、これらは固定証拠であってラベルではありません。観測原子、論理ルール、層間整合、時間持続を同じエネルギーへ入れてターゲット22値を動かし、最終ラベルは必ずターゲット原子Mode(f,c)、Role(f,c)、Rel(f,c)のargmaxで決めます。したがって、NeuPSLは述語名をラベルへ写したあとに微修正する後処理ではありません。

ニューラル述語は証拠値であり、最終ラベルではありません。最終ラベルは、ターゲット述語の層別argmaxで決まります。

最終的に何と比較されるのか — 採点を3段階で確認します

mode（場の様相）、role（音源の正体）、relation（関係）は、採点上は互いに独立した三つのフレーム単位分類問題です。エンジンは各フレームについて、それぞれ一つの最終ラベルを選びます。ここでいう「独立」はGTとの比較と採点を層ごとに分けるという意味であり、推論時に三つを別々に解くという意味ではありません。

分類問題各フレームで分類する対象src/supreme/neupsl.py の正確な語彙
mode（場の様相、10クラス） その場がどのような様相にあるかを分類します。 conv_request, conv_ongoing, surround_activity, forward_caution, side_rear_caution, alert_required, emergency, quiet_standby, env_change, uncertain
role（音源の正体、6クラス） 主な音源が何であるかを分類します。 source_speech, source_vehicle, source_alarm, source_human, source_object, unknown
relation（関係、6クラス） 音源がユーザーや周囲とどのような関係にあるかを分類します。 addressing_user, near_user, approaching, grouped, departing, unrelated

採点は、1フレームの8層を照合し、同じ照合を全フレームへ積み上げ、最後に8本の層別accuracyを平均する順に進みます。図3では、集約評価と同じリビジョンで確認できる段階2・3の値を使って、この順序をたどります。

ここで照合するT2ラベルの正体は、図2で見るとおり、ターゲット述語のクラス引数です。

risk_tier層 1prepass

全体図の段3「前処理（prepass）」 → 音源の切迫度を3段階で示します。

① 何を当てるか音源までの余裕時間から見た、衝突リスクの段階を当てる層です。答えのラベルは info・caution・danger の 3 つです。

② 証拠サイレンの有無、主トラックまでの距離r_m［m］、衝突までの推定時間TTC［s］を使います。r_mは小さいほど近い値です。

③ 決定機構prepass の t0 が担当します。まず主トラックを選びます。siren（サイレン）があればそれを優先し、なければr_mが最小の音源を選びます。次に、TTCを純粋な閾値で判定します。具体的には、siren → danger、ttc < 2.0s → danger、ttc < 8.0s → caution、それ以外はinfoです。NeuPSLは通さず、状態も持ちません。

⑤ 今回の結果（グラフ）N3（PRIMARY）の全適合フレームaccuracyとスイート別accuracyを示します。

t1_state層 2prepass

全体図の段3「前処理（prepass）」 → 距離変化から接近・通過・離脱を判定します。

① 何を当てるか音源が近づいているのか離れているのか、その運動状態を当てる層です。ラベルは idle・approach・pass・depart の 4 つです。

② 証拠現在距離、直前距離、観測中の最短距離、pw_anom、approach_ratio、hazard_trendを使います。距離はmです。pw_anomは0〜1で、大きいほど上流HGFが異常寄りと見た値です。approach_ratioは接近フレームの割合です。hazard_trendの単位と値域は本資料では未確認です。

③ 決定機構

T1は三段階で判定します。まず、ttc_threshold = clamp(12 + 3·pw_anom, [12,15])［s］を使って接近を判定します。

次に、直前状態がapproachなら距離の発散を調べます。cur、min_seen、prev_rangeは距離［m］です。最短距離から1.0mより大きく離れ、かつ直前フレームから0.3mより大きく遠ざかった場合に、5m未満ならpass、10m超ならdepartへ遷移します。

最後に、エピソードのapproach_ratioでapproachを補正し、hazard_trendでdepartまたはidleを補正します。状態は次フレームへ引き継ぎます。

④ 全ラベルと分類数

⑤ 今回の結果（グラフ）N3（PRIMARY）の全適合フレームaccuracyとスイート別accuracyを示します。

この層は4クラスで、最多クラス基準は59.6%です。状態遷移別の再現率は、主評価と同じリビジョンのフレーム成果物がないため本資料では未確認です。

⑥ よくあるつまずき 各フレームを独立に判定すると考えがちですが、直前状態とエピソード集約が次の判定へ引き継がれます。

⑦ なぜ必要か同じ距離でも接近中・通過直後・離脱中では意味が異なるため、利用側へ運動の向きと局面を渡すために必要です。

t2_mode層 3NeuPSL

全体図の段4「T2・NeuPSL」 → 場の様相を10種類から選びます。

① 何を当てるかいまその場がどんな様相か（会話・警戒・環境変化など）を当てる層です。候補はconv_request / conv_ongoing / surround_activity / forward_caution / side_rear_caution / alert_required / emergency / quiet_standby / env_change / uncertainの10種類です。

② 証拠危険・注意・接近・観測品質と、会話・群衆・不確かさを表すニューラル述語を使います。

③ 決定機構

NeuPSL理論補遺 — 凸最適化と射影劣勾配法を開きます

凸最適化の要点

Łukasiewicz緩和で真理値を0〜1へ広げ、E(y)=Σ w·max(0,I(body)−head)² + Σ(p_c+0.005)y_c²を確率単体上で最小化します。実装は最大200反復の決定的な射影劣勾配法です。厳密解は一意ですが、返す値は反復上限内の近似解です。根拠はADR 0052とADR 0053です。

図16は、一意な大域最適を持つ凸地形と、複数の局所解を持ち得る非凸地形の模式比較です。

凸性が成り立つ条件

要素条件
ルール罰max(0,ℓ(y))²は凸です。
重み付き和29本の非負重み付き和も凸です。
一意性クラス別負事前と0.005‖y‖²が強凸性を与えます。
制約mode・role・relationの各確率単体は凸集合です。

射影劣勾配法

  1. 全接地ルール、負事前、Tikhonov項のエネルギーと勾配を計算します。
  2. η_t=0.20/√(1+0.15t)で更新します。
  3. 三層の各ブロックを確率単体へ射影します。
  4. 最大200反復。25反復後、最大変化量が1e-3未満なら終了します。

乱数や時刻を使わないため決定的です。ただし結果は厳密解ではなく近似解です。二乗ヒンジはC1級ですが、名称はADRに合わせて「射影劣勾配法」とします。

推論時は学習済みMLPを固定するため、ニューラル知覚が非凸でも記号推論は凸です。強凸性は厳密解を一意にし、決定的反復は同じ近似解を返します。ADR 0056の実測では60反復以降の層別accuracyが不変で、異なる初期値のargmax一致率は1.000でした。これは数学的証明ではありません。結合MAPは三層と全フレームを同じエネルギーで評価し、層間・時間の不整合をまとめて抑えます。

推論は入力からMAP解を得る前向きの処理ですが、学習はGTから述語パラメータやルール重みを更新する別の処理です。図18を見てください。

NeuPSL理論補遺 — 包絡定理と学習勾配の手計算を開きます

包絡定理の要点

Moreau包絡による値関数の平滑化とは別の話です。値関数をV(ψ)=minₓE(x,ψ)とすると、包絡定理の要点はdV/dψ=∂E/∂ψ（最適解x*を固定）です。強凸性でx*が一意に決まるため、学習へ返す変化率が安定します。図19はこの考え方の模式図です。

谷底では位置ずれが高さへ一次では効かないため、x*の移動経路を微分せず、地形Eの直接変化だけを測れます。谷が複数あると最小点の切替で微分が一意でない場合があります。強凸ならこの切替を避けられます。

微分対象
y*(ψ)の経路ではなく、最適解を固定したエネルギーの変化です。必要なのは、各ψで答えが一つに決まることです。

h_q / vol / pw_anom
h_qは0〜1で大きいほど観測品質が高いスコア、volはHGF層1の事後分散で0以上の無次元値、pw_anomは0〜1で大きいほど異常寄りのスコアです。

F-015はsituations_v1評価アダプタ、F-014-1は学習可能パラメータ数をデータ予算と照合するガードです。
Łukasiewicz 緩和（ウカシェヴィチかんわ）
論理演算を 0 から 1 までの連続値へ拡張する方法であり、含意の違反量を max(0, I(body)−I(head)) として計算できます。
HL-MRF（エイチエル・エムアールエフ）
Hinge-Loss Markov Random Field の略であり、ヒンジ損失のポテンシャルを足した凸エネルギーとして、PSL の連続値推論を表します。
値関数
パラメータごとに、最適化したあとの最良の目的関数値を返す関数であり、この節では、NNのつまみψに対する谷底の高さV(ψ)を表します。
エネルギー
候補解がルールや事前分布をどれだけ破るかを合計した値であり、MAP 推論はこの値が最小の解を探します。
確率単体
各成分が0以上で、同じヘッドの成分和が1になる集合であり、確率分布として許される候補の領域を表す凸集合です。
観測原子
入力から直接得られ、MLP を通さず真理値として使う述語インスタンスであり、本物の配線には 1 フレームあたり 14 個あります。
強凸性
凸性より強く、一つの谷の底が平らに広がらず、最小点が一意に定まる性質であり、supreme8ではε‖y‖²がこの性質を与えます。
結合MAP
複数のヘッドやフレームを別々に解かず、一つのエネルギー最小化として同時に解く方法であり、supreme8ではmode（場の様相）、role（音源の正体）、relation（関係）と全フレームを束ねます。
射影劣勾配法
劣勾配で目的関数を下ったあと、制約集合へ射影して許される解へ戻す反復法であり、supreme8では各ヘッドを確率単体へ戻します。
述語
対象について成り立つ性質や関係を表す関数であり、PSL では値を 0 から 1 までの真理値として扱います。
蒸留
教師モデルや GT から作った軟らかなターゲットを使い、小さなモデルへ知識を移す学習方法であり、ここではニューラル述語の事前学習に使います。
strict OFF
strict_gt_conformance=False で通常推論経路を使う評価条件であり、GT 生成規則の写しによる循環を避けます。
接地
変数を含むルールテンプレートへ具体的なフレームやクラスを代入する操作であり、接地ごとにエネルギーへ加わるポテンシャルができます。
大域最適
許された候補全体のなかで目的関数が最も小さい解であり、凸最適化では局所的な最小点も大域最適になります。
単体射影
更新後のベクトルに最も近い確率単体上の点を求め、非負かつ合計1へ戻す操作であり、supreme8は決定的なソート法で計算します。
凸緩和
0か1に限る離散変数を0から1までの連続値へゆるめ、凸な問題として扱えるようにする変換であり、組み合わせの列挙を避けられます。
凸最適化
凸関数を凸集合上で最小化する問題であり、悪い局所解に捕まらず、大域最適を対象にできます。
NeuPSL
ニューラル述語と PSL の重み付き論理を組み合わせる枠組みであり、supreme8 では T2 三層を結合 MAP で生成します。
ニューラル述語
観測ベクトルを小さな MLP に通して真理値を出す述語であり、本物の配線では 12 個あります。
bilevel（バイレベル）
内側の MAP 推論と外側の学習目的を分けて最適化する二段構造であり、N3 では Moreau 包絡にもとづく BCE 微調整に使います。
ヒンジ損失
違反がないときは 0 で、違反が正になった部分だけを罰する損失であり、supreme8 は違反量を二乗する二乗ヒンジを使います。
PSL（ピーエスエル）
Probabilistic Soft Logic の略であり、論理ルールを連続値へ緩和し、違反量を重み付きポテンシャルとして推論します。
負事前
証拠が乏しいクラス値がむやみに高くならないように加えるクラス別の事前項であり、ルールのエネルギーと一緒に最小化します。
入力契約検査（preflight）
engine実行前にPSOの契約適合性を検査し、適合入力と明示拒否へ分ける処理です。
前処理（prepass）
入力契約検査後、risk、t1、quality、sceneを決め、T2用の特徴を作る決定的な処理です。
包絡定理（Danskinの定理）
最適化後の値がパラメータでどう変わるかを求めるときに、最適解を固定し、目的関数が直接変わる分だけを微分できるという定理であり、この節では、ボールを谷底に置いたまま地形の上下だけを測る考え方に対応します。
ポテンシャル
一つの接地ルールが候補解へ与える非負の罰であり、重み、違反量、ヒンジの次数から値が決まります。
MAP 推論
Maximum A Posteriori 推論の略であり、シナリオ全体の解答用紙の候補から事後確率が最大の1枚を選び、ここでは29本のルールがつける罰金の合計であるエネルギーが最小の1枚を選ぶことと同じ意味になります。
rejection_acc
契約違反入力を明示的に拒否できた割合であり、違反入力を 8 層 accuracy へ混ぜず、別枠で安全性を測ります。
world-first GT
観測やエンジン規則ではなく、先に定めた潜在世界 W から正解を直接導く方式であり、自己採点の循環を構造的に避けます。
窓分類
単一フレームだけでなく、直近の複数フレームを一つの時間窓としてまとめ、その並びや構成比からラベルを選ぶ分類であり、T3はmode系列の直近窓とエピソード累積を使います。
フェーズ宣言
モチーフ脚本が、物語上の現在局面を観測とは別に宣言するintent系譜の情報であり、situations_v1のT3 GTはこの宣言粒度を持つため、観測から推定するT3との間に構造的なずれが生じます。
