第3章　8層の決定と結果を層別に解説します

risk_tier層 1prepass

ひとことで言うと: 音源が衝突リスクになるまでの切迫度を 3 段階で示す層です。

① 何を当てるか音源までの余裕時間から見た、衝突リスクの段階を当てる層です。答えのラベルは info・caution・danger の 3 つです。

② 証拠サイレンの有無、主トラックまでの距離、衝突までの推定時間を使います。

③ 決定機構prepass の t0 が担当します。まず主トラックを選びます。siren（サイレン）があればそれを優先し、なければ最も近い（r_m が最小の）音源を選びます。次に、その TTC（衝突までの推定時間）を純粋な閾値で判定します（ADR 0045）。具体的には、siren → danger、ttc < 2.0s → danger、ttc < 8.0s → caution、それ以外は info とします。NeuPSL は通さず、状態も持たない決定的なルールです。

ステップ1　PSL は論理ルールを連続値で扱います

PSL では、真偽を 0 または 1 に限定せず、0 から 1 までの述語の真理値として表します。含意 A → B の Łukasiewicz 違反量は max(0, I(A)−I(B)) です。証拠 A が強いのに結論 B が弱いほど、ルールを強く破ったと判断します。図を見てください。

ルールは if 文ではありません。

PSL のルールは条件が成立した瞬間にラベルを確定する分岐ではありません。各ルールは候補解へ連続値の罰を加え、すべての罰を合わせた結果として最終解が決まります。

ステップ2　ニューラル述語は観測を真理値へ翻訳します

生の観測だけでは「会話らしさ」や「遠さ」のような中間概念を直接表せません。ニューラル述語は、観測ベクトルを小さな MLP に通し、0 から 1 までの真理値へ変換します。図では、実装と同じ tanh と sigmoid の順序を 1 ユニットに単純化しています。

なぜ凸最適化なのか — 全体の辻褄合わせが必ず同じ答えに着地する理由

導入として、離散の論理割当をそのまま探索する難しさから考えます。 各フレームの各ラベルを0か1だけで決めると、フレーム数とラベル数が増えるたびに候補の組み合わせが爆発します。supreme8は、Łukasiewicz緩和で各真理値を0から1までの連続値へゆるめる凸緩和を使います。この変換によって、候補を一つずつ列挙する探索問題が、連続値の凸最適化へ変わります。これは、ヒンジ損失で連続値の論理を表すHL-MRFの設計思想です。

「MAPは凸緩和の劣勾配法であり、反復上限内での近似解（決定的）である。」

仕組みとして、目的関数と制約を一つずつ凸に組み立てます

1各ルールの罰が凸になります

接地した各ルールは、ターゲット変数yに対してアフィンな違反量ℓ(y)を作り、max(0, ℓ(y))²を罰として加えます。アフィン関数に二乗ヒンジを合成したこの関数は凸です。

2重み付き和も凸のままです

29本のルールは非負重みwを持ちます。凸関数を非負重みで足しても凸なので、Σ w·max(0,ℓ(y))²も凸になります。

3二次項が最小点を一意にします

クラス別負事前のp_c·y_c²は凸二次関数です。さらに、ε‖y‖²をε=0.005で加えるため、目的関数は強凸性を持ち、厳密な最小点が一つに定まります。

4許される領域も凸になります

各フレームのmode（場の様相）、role（音源の正体）、relation（関係）は、各成分が非負で合計が1になる確率単体上に制約されます。単体は凸集合なので、二つの許される解を結ぶ線分もすべて許される解になります。

以上をまとめると、supreme8の記号推論は「凸関数を凸集合上で最小化する問題」です。したがって、局所的な最小点はそのまま大域最適であり、非凸最適化のように悪い局所解へ閉じ込められません。εIのTikhonov項が強凸性を与えるため、理論上の厳密解は一意です。

NNと凸最適をつないで学習できる理由 — ボールは動かさず、地形だけを測ります

学習が知りたいのは、NNのつまみであるパラメータを少し回すと、答えの良さがどれだけ変わるかです。ここでは、つまみを回すことを「谷の地形が少し変わること」、凸最適化の答えを「谷底に置かれたボール」と考えます。

つまみをψ、ボールの位置をx*、地形の高さをE(x,ψ)と書きます。谷底の高さV(ψ)=minₓ E(x,ψ)は、つまみに対して最良の高さを返す値関数です。バックプロパゲーションが次へ渡したいのは、つまみを少し回したときのVの変化率です。

追いたいのは、ボールの道順ではなく、底の高さの変化です

図では、難しそうに見える方法と、実際に使える方法を二つのコマで比べます。

谷底では、ボールが動ける方向に沿って地面が平らです。そのため、ボールが少しずれても、高さは一次近似では変わりません。最初に効く変化は地形そのものの上下なので、ボールを今の谷底に固定したまま、地形だけをつまみで微分してよいことになります。

この考え方を包絡定理（Danskinの定理）と呼びます。名前は難しく見えますが、要点はdV/dψ = ∂E/∂ψ(x*を固定)という一行です。ボールがどの道を通ったかを微分せず、今いる谷底で地形が上下する速さだけを測ります。

谷が一つだから、測る底が途中で入れ替わりません

谷が二つあると、つまみを少し回した瞬間に、最も低い谷が隣へ切り替わり、ボールがジャンプすることがあります。このとき、高さそのものが消えるのではなく、高さの変わり方がガクンと切り替わり、折れ曲がる点では微分が一つに定まりません。

強凸なら谷は一つなので、どの谷を測るかが途中で入れ替わりません。つまり、「強凸なら答えが一つに決まる」という一意性が、学習へ返す変化率を安定させます。これが、ADR 0053の「MAPを一意化して学習勾配を安定させる」という設計の正体です。

結合 MAP とは — 全部を同時に決める仕組み

「結合」とは、フレームも層も別々に決めず、シナリオ全体を一つの最適化問題として同時に解くことです。変数は全フレーム×値であり、eval の平均 フレームのシナリオでは約 変数になります。

図では、二つのフレームとmode（場の様相）・role（音源の正体）の二層だけを抜き出し、三種類のルールが違反コストの綱として変数を結ぶ様子を示します。

結合 MAP は E(y)=Σ w×違反² を全変数について最小化し、射影劣勾配法を約 200 反復する決定的な手順で、各層の値を確率単体へ戻しながら更新します。最適化が終わると、各フレームの各層でargmaxを取り、mode（場の様相）、role（音源の正体）、relation（関係）の三つの最終ラベルを確定します。

結合をどのようにイメージすればよいでしょうか。

結合 MAP はクロスワードパズルに似ています。1 マスずつ独立に埋めるのではなく、縦と横の答えが同時に整合するように全マスを決めるのと同じように、全フレームと全層の辻褄が合う解を探します。これは計算内容を単純化したおもちゃの例ではなく、「結合」の考え方をつかむための比喩です。

MAP は述語の出力を後処理で微修正するのでしょうか。

MAP はニューラル述語の出力を後処理で微修正するものではありません。述語値は固定の証拠として入り、ターゲット 22 値の側を全体整合が取れるまで動かします。

NeuPSL は後処理ではありません。

NeuPSL はニューラルモデルが出したラベルを最後に整えるだけの処理ではありません。ニューラル述語の真理値、観測原子、論理ルール、層間整合、時間持続を一つのエネルギーへ入れ、T2 のラベルそのものを結合 MAP で生成します。

NeuPSL より前に入力を検証し、risk、t1、quality、scene を決める決定的な前処理です。T2 が使う特徴もここで作ります。
包絡定理（Danskinの定理）
最適化後の値がパラメータでどう変わるかを求めるときに、最適解を固定し、目的関数が直接変わる分だけを微分できるという定理です。この節では、ボールを谷底に置いたまま地形の上下だけを測る考え方に対応します。
ポテンシャル
一つの接地ルールが候補解へ与える非負の罰です。重み、違反量、ヒンジの次数から値が決まります。
MAP 推論
Maximum A Posteriori 推論の略です。ここでは事後確率を最大にすることと等価な、エネルギーを最小にする解を探します。
rejection_acc
契約違反入力を明示的に拒否できた割合です。違反入力を 8 層 accuracy へ混ぜず、別枠で安全性を測ります。
world-first GT
観測やエンジン規則ではなく、先に定めた潜在世界 W から正解を直接導く方式です。自己採点の循環を構造的に避けます。
