③ NeuPSL の共通基盤（3 要素と学習レシピ）

T2 の 3 層（mode / role / relation）は同じ NeuPSL 機械の上で解かれる。層別解説の前に、その共通部品をまとめて示す。

① ニューラル述語（ 個）
入力 1〜4 次元 → 隠れ （tanh）→ sigmoid の微小 2 層 MLP。決定的初期化・出力バイアス −2.0 で「未学習時はほぼ沈黙、学習で立ち上がる」。生特徴を軟真理値 [0,1] に写す。観測述語 個は MLP を通さず入力値をそのまま真理値に使う。
② Łukasiewicz ルール（ 本）
連言 I(A∧B)=max(0,a+b−1)、否定 ¬a=1−a、含意 A→B の違反量 max(0,I(A)−I(B))。「重み×違反量」の総和がエネルギー。重みは学習対象。
③ 結合 MAP 推論（HL-MRF）
シナリオ内の全フレーム×3 層の開述語（mode ＋role ＋rel ）を二乗ヒンジ＋εI Tikhonov のエネルギーとして同時最適化（射影劣勾配・層ごと確率単体へ射影）。時間持続ルール Mode(f−1,m)→Mode(f,m) が全フレームを 1 つの MAP に束ねる。全経路が決定的。

学習レシピ（4 段パイプ・T2 各層はこの上で学習される）

ADR 0056（研究世代）の知見： 寄与は 事前学習 ≫ 二乗ヒンジ ≫ その他。性能源泉はニューラル述語のラベル蒸留事前学習と二乗ヒンジのポテンシャル整形にあり、role は少数述語に一点依存、mode/rel は語彙上限付近で学習残余が大きい。

N3（PRIMARY）レシピの実測時間（results.json）：t3/scene 学習 s ／ T2 基礎 6 エポック s ／ bilevel 2 エポック + ≥ガード s。≥ガード（最大 400 練習シナリオ）で 学習 vs 事前重み を比較し、学習が事前重みを下回れば事前重みを採用する（学習が悪化させない担保）。

結果解釈に必要な測定条件（strict OFF と監査是正・圧縮版）:
strict OFF 必須（strict_gt_conformance=False・ADR 0050）— strict ON 写し（gt_derive の規則 f）を適用すると循環スコア（ADR 0049 撤回）が再生するため、能力評価では T2 を NeuPSL 結合 MAP 経路へ通す。
監査 P0 是正 — t3/scene 学習の mode 系列を strict ON view から strict OFF 公開 API（run_supreme_scenarios(..., strict_gt_conformance=False)）由来へ変更（P0-2）。全 train 非違反入力を fit 前 preflight し false reject は学習除外（P0-1・今回 train_false_reject 件）。
rejection 別採点 — 契約違反 eval は 8 層採点の分母から除外し、明示拒否の当否のみ rejection_acc で測る（eval /＝）。

④ 全 8 層の層別解説（今回の結果と構造的理由）

各層について「何を当てる層か」「supreme8 はどう決めるか」「今回の結果（N3 pooled ＋ suite 別顕著点・機械生成）」「解釈（構造的理由）」を示す。推測は「推定」と明示する。

risk_tier層 1prepass

何を当てる層か 音源までの余裕時間から見た衝突リスクの段階。語彙 info / caution / danger。

supreme8 はどう決めるか prepass の t0。主トラックを siren 優先・なければ最近傍（最小 r_m）で選び、その TTC を純閾値で判定する（ADR 0045）：siren → danger、ttc < 2.0s → danger、ttc < 8.0s → caution、それ以外 info。NeuPSL は通さず、決定的・状態レス。

解釈 観測ベースの決定的ルールなので suite 横断で安定。emg が低い（）のは、緊急スイートの TTC 分布・GT 定義が純閾値と系統的にずれるためと推定。循環リスクはない（GT 写しを使わない）。

t1_state層 2prepass

何を当てる層か 音源の接近・離脱の運動状態。語彙 idle / approach / pass / depart。

supreme8 はどう決めるか prepass の t1 状態機械。ttc_threshold = clamp(12 + 3·pw_anom, [12,15]) で接近判定。前状態が approach なら発散判定：(cur − min_seen) > 1.0 かつ (cur − prev_range) > 0.3 で、近ければ（< 5m）pass・遠ければ（> 10m）depart。エピソードの approach_ratio で approach 固定、hazard_trend で depart/idle を補正。状態は外部注入で連鎖。

解釈 安定して高く、suite 間の分散が小さい（最低でも 級）。観測ベースの状態機械で循環リスクがなく、prepass 3 層のなかでも堅い。

t2_mode層 3NeuPSL

何を当てる層か 場の様相（会話・警戒・環境変化など）。語彙 10：conv_request / conv_ongoing / surround_activity / forward_caution / side_rear_caution / alert_required / emergency / quiet_standby / env_change / uncertain。

supreme8 はどう決めるか 観測特徴 risk_danger/risk_caution（t0 由来）・approaching（t1 由来）・h_q が、ニューラル述語 ConvEv[speech,speaking,range_n] / SpkOnly[spk_link,addr_link] / CrowdEv[humans_n,speaking] / LowQ[h_q] / UncEv[h_q,range_n,spk_link,speaking] を発火させ、mode 向けルール群へ入る。代表： r_danger_emerg (w5.0) risk_danger → Mode(emergency) r_conv_ongoing (w4.0) ConvEv → Mode(conv_ongoing) r_lowq_env (w4.0) LowQ → Mode(env_change) r_unc_mode (w3.0) UncEv → Mode(uncertain) 〔ADR 0057〕 これらを結合 MAP で role/rel と同時最適化。時間持続 t_persist_mode（w1.2）が (フレーム数−1)× モードぶん接地されて全フレームを 1 つの MAP に束ね、層間ルール x_emerg_alarm が role へ、x_surround_group が rel へ波及する。

解釈 T2 で最低。語彙が 10 と広く、語彙上限（理論上 1.0）付近でコスト感応マージンを効かせても学習残余が大きい（ADR 0056）。crw が最高（）なのは CrowdEv→surround/grouped の群衆整合が結合 MAP で効くためと推定。dcp が最低（）は「観測が嘘をつく罠」スイートで、低いのは設計意図（天井が構造的に 1.0 未満）。

t2_role層 4NeuPSL

何を当てる層か 主たる音源の正体。語彙 6：source_speech / source_vehicle / source_alarm / source_human / source_object / unknown。

supreme8 はどう決めるか 述語 SpeechSrc[speech,speaking,spk_link] / HumanSrc[humans_n,speech,range_n] / ObjSrc[objects_n,vehicle,alarm] はラベル蒸留で事前学習される（GT 由来ターゲットで BCE・pretrain_predicates）。代表： r_speech_role (w2.0) SpeechSrc → Role(source_speech) r_human_role (w1.0) HumanSrc ∧ ¬SpeechSrc ∧ ¬alarm → Role(source_human) r_siren_alarm / r_alarm_alarm (w2.0) siren / alarm → Role(source_alarm) 結合 MAP で x_ongoing_speech（Mode(conv_ongoing)→Role(source_speech)）・x_emerg_alarm が mode と整合する。

解釈 T2 で最高。蒸留事前学習された少数述語（SpeechSrc/HumanSrc/ObjSrc）に一点依存する構造で（ADR 0056：寄与は事前学習 ≫ 二乗ヒンジ）、emg/crw/crp で 0.85〜0.90 級（例：emg ）。dcp が最低（）は欺瞞スイートで設計どおり。

t2_relation層 5NeuPSL

何を当てる層か 音源とユーザーの関係。語彙 6：addressing_user / near_user / approaching / grouped / departing / unrelated。

supreme8 はどう決めるか 述語 AddrEv[call_user,addr_link,near3,spk_link] / DepEv[t1_depart,range_n,approaching] / FarEv[range_n,near3,humans_n,spk_link] ＋ 観測 approaching。代表： r_addr_rel (w2.5) AddrEv → Rel(addressing_user) r_appr_rel (w2.0) approaching → Rel(approaching) r_t1dep_rel (w3.0) t1_depart → Rel(departing) 〔ADR 0057〕 r_far_unrel (w2.0) FarEv ∧ ¬approaching → Rel(unrelated) 〔ADR 0057〕 結合 MAP で x_request_addr（Mode(conv_request)→Rel(addressing_user)）が mode と整合する。

解釈 中位。addressing/approaching/near は効くが、ADR 0057 で追加した departing/unrelated は現特徴（t1_depart・距離）では分離不十分で回収が限定的 — relation ラベルの約 48% を占めるにもかかわらず（ADR 0058 の正直な評価）。これはバグではなく既知の設計限界（新述語向けの特徴拡充と蒸留ターゲット再設計が前提）。bst で高い（）。

t3_hypothesis層 6T3 統合

何を当てる層か 時系列で見た状況仮説。語彙 10：quiet_stable / conv_participating / sustained_alert / env_shift / env_start / crowd_tendency / traffic_unstable / hazard_declining / uncertain_context / alert_required。

supreme8 はどう決めるか prepass 後段の t3。NeuPSL の mode 出力系列を有界窓（≤ W）＋エピソード集約（持続 conv 比率／切替率／flip 累積／posterior 平均・分散・トレンド）に畳み、局所ロジスティックで conv/traffic/quiet の 3 境界を作って argmax、他クラスは規則層で割付。reset=frame0 でエピソード初期化。学習 param ≪ 予算 100。監査 P0-2 是正で、集約に入る mode 系列を strict OFF 公開 API 由来に統一した。

解釈 低め。入力が NeuPSL の mode 出力なので mode の品質に連動する（mode が低いと下流の t3 も押し下がる）。dcp（）・bst（）で顕著に低いのは mode 低下の伝播と推定。crw で高い（）。

quality_regime層 7prepass

何を当てる層か 観測品質のレジーム。語彙 GOOD / DEGRADED / BLOCK。

supreme8 はどう決めるか prepass の quality。h_q（＋層 1 事後分散 vol）を優先順位チェーンで分類（ADR 0014）：h_q<0.25→BLOCK、h_q<0.40 ∧ vol>0.05→BLOCK、h_q<0.55→BLOCK、h_q≥0.93 ∧ vol<0.01→GOOD、それ以外 DEGRADED。決定的な純関数。

解釈 全 8 層で最高（pooled ）。優先順位チェーンが安定。crp（破損）だけ低い（）のは破損スイートの特性。

scene_regime層 8prepass · HGF

何を当てる層か シーン全体の変化レジーム。語彙 STABLE / CHANGING / DEGRADING。

supreme8 はどう決めるか prepass の scene。HGF 3 層カーネルで潜在水準 μ1（層 1）と log-volatility（層 2）を階層推定し（層 2 が持続的変化を捕捉）、持続性特徴（nominal からの逸脱の漏れ積分）を加え、閾値で 3 クラス分類（DEGRADING 含む）。HGF param ＋ 閾値のみ学習（ ≪ 予算 100）、監査是正後は strict OFF view で fit する。

解釈 中位。dcp（）・std（）で高く、crp（）・emg（）で低いのは破損・緊急スイートの特性（破損下は Safety Latch が働き天井が構造的に 1.0 未満・設計意図）。

⑦ 正直な注記

既存テスト失敗（F-015 と無関係）: SupremeParams.learnable_param_count() ＝ （NeuPSL + t3 + scene ）が閾値 360 を超過し、 F-014-1 の param≪data ガードテスト（tests/test_Phase1_learning_wiring.py）が master 基点で既に失敗している （ADR 0057 の新ルールで学習パラメータが増加）。F-015 の全変更を退避しても再現する既存の失敗であり、F-015 のテスト自体は全緑。
  • GT は規則生成のため、学習が獲得するのは「仕様規則への汎化」。能力の主張には独立ラベラ（f_blind）照合の併記が要る（ADR 0049 継承）。situations_v1 はその循環を GT の潜在世界直接導出で構造排除した別土俵。
  • モチーフ有限性：train/eval は同一 50 モチーフの別パラメタ。最終確定測定（seal）には完全新作モチーフが必要（生成器側の宿題）。
  • MAP は近似解：凸緩和の劣勾配法で反復上限内の決定的近似解である。
